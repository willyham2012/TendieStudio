# The real `.tendies` format (as verified)

Everything here was checked against **real files**: 15 wallpapers downloaded from CAPlayground's public
collection (`CAPlayground/wallpapers`), plus CAPlayground's open-source parser/serializer and Nugget's
documentation. `Tools/validate_tendies.py` accepts all 15; the exporter reproduces this layout.

A `.tendies` is a plain ZIP (stored/deflate, UTF-8 names, directory entries included):

```
descriptors/<UUID>/                              (UUID is 09E9B685-7456-4856-9C10-47DF26B76C33 in every sample)
  com.apple.posterkit.provider.descriptor.identifier       "7400"
  com.apple.posterkit.role.identifier                      "PRPosterRoleLockScreen"
  com.apple.posterkit.provider.identifierURL.suggestionMetadata.plist   (binary NSKeyedArchiver)
  providerInfo.plist                                        (binary NSKeyedArchiver)
  versions/1/
    RuntimeSnapshotMetadata-{home,lock}.plist
    com.apple.posterkit.provider.instance.{complicationLayout,titleStyleConfiguration}.plist
    contents/
      .com.apple.posterkit.provider.contents.configurableOptions.plist
      com.apple.posterkit.provider.contents.{otherMetadata.plist,userInfo}
      7400.WWDC_2022-390w-844h@3x~iphone.wallpaper/
        Wallpaper.plist                     assets.lockAndHome.default.{type: LayeredAnimation, *AnimationFileName}
        7400.WWDC_2022_Background-390w-844h@3x~iphone.ca/   index.xml, assetManifest.caml, main.caml, assets/Root_Layer.js
        7400.WWDC_2022_Floating-390w-844h@3x~iphone.ca/     index.xml, assetManifest.caml, main.caml, assets/<images>
        7400.WWDC_2022_Foreground-390w-844h@3x~iphone.ca/   index.xml (long form), assetManifest.caml, main.caml
```

* Every community file is a re-skin of Apple's "WWDC 2022" (id 7400) wallpaper template. All template files
  except `main.caml` and `assets/` are **byte-identical across samples**, so TendieStudio embeds them verbatim
  (`Export/TendiesTemplate.swift`, generated by `Tools/gen_template.py`).
* Nugget's docs describe two *restore* layouts (`container` and `descriptor(s)`); community `.tendies` use the
  **descriptors** layout above. Nugget randomises descriptor UUIDs on restore.
* `.ca` package = `index.xml` (plist, `rootDocument` = `main.caml`) + `main.caml` (CAML) + `assets/`.
* CAML: `<caml xmlns="http://www.apple.com/CoreAnimation/1.0">`, `<CALayer … bounds position …>`,
  `<contents><CGImage src="assets/x.png"/></contents>`, `<animations><animation type="CAKeyframeAnimation"
  keyPath=… beginTime="1e-100" repeatCount="inf" calculationMode="linear"><values><CGPoint|real value=…/>`.
* Animation key paths seen in the wild: `position`, `transform.rotation.z`, `opacity`, `zPosition`, `position.y`,
  `contents` (frame sequences); `CASpringAnimation` is used only in state transitions.
* **Coordinates are top-left, y-down, unconverted** (verified by comparing a wallpaper's Locked-state layer
  positions with its published preview). Document size varies per file (390×844, 402×874, 440×956, 1170×2532…)
  inside the same `390w-844h@3x~iphone` folder name, so the folder name is *not* a size selector.
* Mercury poster containers are a different structure; we reject them (as CAPlayground does).

## What is *not* verified
* Rendering on iOS 26/27 on a 14 Pro Max. No sample targets 430×932; we follow the proven "any doc size in the
  standard folder" pattern. **Device test required.** `Samples/…TestPattern_14ProMax.tendies` exists for this.
* `transform.scale` keyPath (scale animations) was not present in the samples. Warned at export.
* Easing: `keyTimes`/`timingFunctions` never appear in samples, so easing is **baked into 30 Hz samples**.

## Community collection & submission (verified from CAPlayground's source)
* Gallery = one public JSON, `CAPlayground/wallpapers/wallpapers.json` (`base_url` + `{id,name,creator,description,file,preview,date}`),
  files and GIF previews are static files in that repo. TendieStudio reads it read-only.
* **No publishing API.** The website opens a GitHub pull request (branch `dev`, paths `wallpapers/`, `previews/video/`,
  `jsons/`) using the signed-in user's token; maintainers review. TendieStudio does not automate or bypass this —
  it exports a validated file and links to the official flow.
