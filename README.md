# TendieStudio

A native, local-first iOS studio for creating, animating, saving and sharing custom wallpapers. Designed with the sideloading community in mind.

> **Status:** Concept / early development. No functional app or IPA has been released yet.

## Vision

- **Discover:** Browse and preview community-made animated wallpapers. Explore potential CAPlayground integration, subject to its actual APIs and submission rules.
- **Studio:** Import artwork, arrange layers, animate with keyframes and effects, and preview the result directly on-device.
- **Library:** Keep editable projects, drafts and downloaded wallpapers locally, with offline access.
- **Export:** Investigate the real `.tendies` format and validate exported files with compatible tools before claiming support.
- **Share:** Optional community publishing, without requiring an account for offline creation.

## Principles

- Native Swift / SwiftUI experience.
- Local-first editing and storage; no required cloud account or paid AI APIs.
- Functional, polished interactions rather than mock interfaces.
- Respect iOS sandboxing, sideloading and signing constraints.
- Clearly separate planned features from implemented and tested features.

## First milestone

Import an image, animate it, preview it, save an editable project and export a verified compatible wallpaper format where feasible.

## Development

An Xcode project and build instructions will be added as development begins. Contributions and feature discussions are welcome.
